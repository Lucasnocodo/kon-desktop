# Qt for Python license texts

These unmodified license texts were verified byte for byte against the official
Qt for Python **v6.9.3** source tag, `LICENSES/`:
https://github.com/pyside/pyside-setup/tree/v6.9.3/LICENSES

The same standardized text bytes also occur on the upstream `6.12` branch,
where the initial copies were retrieved. They are not version-specific grants
from KON. The license terms declared by the installed distributions remain the
authority; the bundled `installed-components.json` records actual installed
versions, and `Runtime-NOTICE.txt` generates matching versioned upstream source
locations on every build. Text licenses supplied by the installed distributions
are preserved separately.

The PySide6-Essentials and Shiboken6 runtime metadata declares
`LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only`. These texts accompany the
binary distribution and its dynamically linked libraries. The Qt exception text
is included for upstream reference; it does not replace the applicable
LGPL/GPL terms.
