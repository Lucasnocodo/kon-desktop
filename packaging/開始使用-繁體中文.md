# KON macOS 版 — 開始使用

需要 Apple 晶片 Mac 與 macOS 14 以上。App 已包含 Python、模型與 CPU 語音辨識，
不必安裝 Python、Xcode 或執行安裝腳本。最低版本是經二進位檢查的相容目標；
實際測試的 macOS 版本與驗證範圍請見 `Release.json`。

1. 從同一個官方 GitHub Release 下載 ZIP 與 `SHA256SUMS`：
   https://github.com/Lucasnocodo/kon-desktop/releases
2. 在「終端機」切換到下載資料夾，執行 `shasum -a 256 -c SHA256SUMS`。
   ZIP 應顯示 `OK`。雜湊核對下載內容，不代表發行者身分；請使用官方發布頁。
3. 解壓縮 ZIP，將 `KON.app` 拖入「應用程式」，再從該處開啟。
4. 本版採 ad-hoc 簽章，**未經 Apple 公證**。若 macOS 提示無法驗證開發者，
   先核對官方來源與雜湊，嘗試開啟後，依系統「設定 → 隱私權與安全性 →
   仍要打開」允許這一個 App。Apple 官方說明：https://support.apple.com/zh-tw/102445
   如果系統指出惡意軟體或檔案損壞，請停止開啟並回報完整錯誤。
5. 語言選單可切換繁體中文與 English；初次依已存設定或系統語言選擇。
   開啟控制台不會啟動鏡頭與麥克風；先試「預覽狐狸吞噬動畫」。
6. 選手圈移動控制準星或眼睛穿過手圈瞄準，再明確啟動感測器，依提示授予 KON
   鏡頭與麥克風權限，完成畫面上的瞄準與手勢校正。鎖定目標後發出新的短音
   才召喚靈狐；咒語文字辨識是可選的本機 CPU 模式。
7. 桌面模式會將主螢幕桌面上選定的一般檔案移至垃圾桶，必要時要求 Finder
   自動化權限。先用虛擬演練熟悉操作；復原只還原最近一次操作，不覆寫同名檔案。
   本版使用單鏡頭。

設定與個人數值校正存於 App 外的 `~/Library/Application Support/KON Desktop/`。
不保存鏡頭影像與麥克風錄音；更新前先結束 KON 再替換 App。
壓縮包附驗證報告與第三方授權。自動檢查只使用合成／空白影像及公開音訊範例，
不開啟感測器，也不操作真實 Finder 檔案；不代表個人瞄準精度已通過實測。
